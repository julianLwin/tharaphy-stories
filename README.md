# Tharaphy Stories

Instagram story images for [@tharaphyny_amigurumi](https://www.instagram.com/tharaphyny_amigurumi/), made every other day by a scheduled Claude routine.

- `stories/<date>/`: the images for each run. Open one and use **Download** to save it.
- `story-template.html`: the shared design (styles, sparkles, example slides).
- `story-log.md`: every story made so far, so runs don't repeat.
- `render.py`: turns a story HTML file into 1080×1920 PNGs.
